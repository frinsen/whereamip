# Security policy

## Supported versions

Only the latest release on the [releases page](https://github.com/frinsen/whereamip/releases/latest) receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting instead:
<https://github.com/frinsen/whereamip/security/advisories/new>

You will get an acknowledgement within a few days. Once a fix is released, the
advisory is published with credit to the reporter unless you prefer otherwise.

## Scope notes

WhereAmIP runs unprivileged, writes nothing to disk except its preferences, and
makes only the network requests documented in the README's Privacy section.
Reports about those requests, the DNS check, the update check, or the
diagnostics report are especially welcome.
