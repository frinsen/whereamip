- **What's New is one click away.** Settings now has two explicit entries: *Show
  Welcome Window* for the tour, *Show What's New* for the release highlights —
  this window. Both got a redesign: a small badge says which one you are
  looking at, and the sections finally have room to breathe.
- **The update row knows how you installed WhereAmIP.** Homebrew installs get
  the brew command, MacPorts installs the port command, and a downloaded zip
  gets the releases page — no more copying a command that was never going to
  work on your machine.
- **Installing on older Xcode works again.** A dependency had quietly started
  requiring a newer Swift than Xcode 16.2 ships; it is pinned back, so
  from-source installs build everywhere macOS 13 and up.
